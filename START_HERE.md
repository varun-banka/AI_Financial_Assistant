## 🚀 Getting Started (5 Steps)

### Step 1: Install Dependencies (2 minutes)
```bash
cd c:\AI_Financial_Assistant
pip install -r requirements.txt
```

### Step 2: Setup API Key (1 minute)
Edit `.env`:
```
GOOGLE_API_KEY=your_gemini_api_key_here
```
Get free key: https://aistudio.google.com/app/apikey

### Step 3: Start Application (30 seconds)
```bash
streamlit run app.py
```

### Step 4: Upload a PDF (1 minute)
- Click **📤 Upload & Process**
- Upload a financial PDF
- Click **🚀 Process PDF**
- Wait for ✅ success

### Step 5: Ask Questions (30 seconds)
- Click **❓ Ask Questions**
- Type: "What was the revenue?"
- See answer with citations

**Total time: ~5 minutes from zero to working!**

## 🔑 Key Features Explained

### 🧠 RAG Pipeline (Phases 1, 2, 9)
- Upload PDF → Split into chunks → Create embeddings → Store in FAISS
- User asks question → Retrieve relevant chunks → Generate answer with LLM
- Result: Accurate answers with source citations

### 💰 Financial Intelligence (Phase 2)
- Automatically extract: Revenue, Profit, Assets, Liabilities, Equity
- Calculate 10 ratios: ROE, Profit Margin, D/E, Current Ratio, etc.
- Show profitability, liquidity, and leverage metrics

### 🔄 Hybrid Search (Phase 7)
- Vector search (FAISS) for semantic similarity
- Keyword search (BM25) for exact matches
- Combined: 0.7 × Vector + 0.3 × BM25 = Better results

### 💬 Conversation Memory (Phase 6)
- Track multi-turn conversations
- Detect follow-up questions
- Maintain context across turns
- Export conversation history

### ⚠️ Risk Analysis (Phase 8)
- Identify business risks
- Classify sentiment
- Find opportunities
- Generate assessment

### 📋 Executive Summary (Phase 9)
- Auto-generate summaries
- Provide metrics overview
- Investment recommendations
- Compare companies

## 🐛 If Something Doesn't Work

### Problem: "ModuleNotFoundError"
**Fix**: `pip install -r requirements.txt`

### Problem: "GOOGLE_API_KEY not set"
**Fix**: Check `.env` file, add your key, restart app

### Problem: "streamlit: command not found"
**Fix**: `pip install streamlit==1.28.1`

### Problem: "PDF not processing"
**Fix**: Ensure it's a text-based PDF (not scanned)

### Problem: "No vector store found"
**Fix**: Upload and process a PDF first
